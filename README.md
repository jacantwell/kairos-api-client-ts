# kairos-api-ts
Typescript API client for Kairos backend.

# Generation

To generate the client run:

```bash
npx @openapitools/openapi-generator-cli generate -g typescript-axios -o src -i https://7zpmbpgf7d.execute-api.eu-west-2.amazonaws.com/api/v1/openapi.json
```

# Usage

To install the client run:

```bash
npm install github:jacantwell/kairos-api-client-ts
```
